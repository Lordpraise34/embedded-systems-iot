# Smart Environmental Monitoring and Alert System (SEMAS)

## Overview

SEMAS is an embedded systems project designed to monitor environmental conditions using sensors and provide alerts based on predefined thresholds.

## Features

- Temperature Monitoring
- Light Detection
- Automated Alerts
- ESP32 Microcontroller
- Sensor Integration

## Technologies Used

- ESP32
- Arduino IDE
- C++
- LM35 Temperature Sensor
- LDR Sensor

## Project Status

Completed as an undergraduate engineering project.

## Future Improvements

- Wi-Fi Remote Monitoring
- Mobile Application
- Cloud Data Storage
- OLED Dashboard
